## 1. 设计原则

**初期桥接，远期自建。** 不重写 Hermes 现有的 30+ 工具实现，而是通过桥接层代理执行。

| 阶段 | 工具来源 | 工具数量 | 时机 |
|:-----|:---------|:--------:|:-----|
| Phase 0 | 全部桥接到 Hermes | 全部 | MVP |
| Phase 1 | 核心工具自建 + 其余桥接 | ~10 自建 | 稳定后 |
| Phase 2 | 全部自建 | 全部 | 远期 |

## 2. 桥接架构

```
LLM 请求工具调用
    │
    ▼
05 模块 ToolBridge
    │
    ├── 工具路由
    │   ├── 自建工具 → 直接执行（Phase 1+）
    │   └── Hermes工具 → 桥接执行
    │
    ▼
Hermes ToolExecutor
    │
    └── 执行真实工具（terminal/read_file等）
    │
    ▼
结果返回 → 注入回 LLM 对话
```

### 2.1 桥接协议

```python
class ToolBridge:
    def __init__(self, hermes_agent_ref=None):
        self.hermes = hermes_agent_ref  # Hermes 实例引用
        self.builtin_tools: Dict[str, Tool] = {}  # 自建工具
    
    async def execute(
        self, 
        tool_call: ToolCall
    ) -> ToolResult:
        """执行工具调用"""
        if tool_call.function.name in self.builtin_tools:
            return await self._execute_builtin(tool_call)
        elif self.hermes:
            return await self._bridge_to_hermes(tool_call)
        else:
            return ToolResult(
                tool_call_id=tool_call.id,
                error=f"Unknown tool: {tool_call.function.name}"
            )
    
    async def _bridge_to_hermes(
        self, 
        tool_call: ToolCall
    ) -> ToolResult:
        """桥接到 Hermes 执行"""
        try:
            # 通过 Hermes 的 handle_function_call 执行
            result = self.hermes.handle_function_call(
                name=tool_call.function.name,
                args=json.loads(tool_call.function.arguments)
            )
            return ToolResult(
                tool_call_id=tool_call.id,
                output=str(result)
            )
        except Exception as e:
            return ToolResult(
                tool_call_id=tool_call.id,
                error=str(e)
            )
```

### 2.2 安全性

工具执行受模块11（安全门闸系统）的保护。所有 terminal 命令在执行前经过决策门闸审核。

## 3. 工具调用循环控制

```python
MAX_TOOL_CALLS_PER_TURN = 10  # 每轮最多10次工具调用
MAX_TOOL_DEPTH = 3             # 最多3层嵌套（LLM→工具→结果→LLM→工具→结果→LLM→回复）

class ToolLoopController:
    def __init__(self):
        self.call_count = 0
        self.depth = 0
        self.executed_tools: List[str] = []
    
    def can_proceed(self) -> bool:
        return (self.call_count < MAX_TOOL_CALLS_PER_TURN 
                and self.depth < MAX_TOOL_DEPTH)
```

## 4. 自建工具规划（Phase 1）

| 工具 | 优先级 | 说明 |
|:-----|:------:|:-----|
| terminal | P0 | shell 命令执行 |

| search_files | P0 | 文件搜索 |

| web_search | P1 | 联网搜索 |
