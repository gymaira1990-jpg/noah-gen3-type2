# 原铸诺亚 · 产品手册

## 这是什么

原铸诺亚（Primaris Noah）是 **0101 型诺亚的模块化管理体系**。它将诺亚的能力拆解为 7 个 NCP 模块，每个模块对应一组可独立维护的技能文件和运行时组件。

```
                    ┌──────────────────────────────┐
                    │        原铸诺亚 v1.0.0         │
                    │    (Hermes Agent v0.13.0)     │
                    └──────────────────────────────┘
                                │
         ┌──────────────────────┼──────────────────────┐
         │          │          │          │           │
    ┌────┴───┐ ┌───┴────┐ ┌───┴────┐ ┌──┴────┐ ┌────┴───┐
    │ 路由层  │ │ 知识层  │ │ 记忆层  │ │ 安全层  │ │ 运营层  │
    │NCP-007 │ │NCP-008 │ │NCP-010 │ │NCP-011 │ │NCP-012 │
    │NCP-009 │ │        │ │        │ │        │ │NCP-013 │
    └────────┘ └────────┘ └────────┘ └────────┘ └────────┘
```

## 模块清单

### 🟢 NCP-007 · P4 Router (v2.0.0)
**多 AI 提供商智能路由。** 余额感知、自动降级链、任务类型精细路由、延迟监控。
- 独立代码仓库: `~/p4-router/`（1.2MB, 34 文件）
- PG pgvector 向量语义匹配层
- 三方适配器: DeepSeek / 火山引擎（豆包Ark） / NVIDIA NIM
- FastAPI 管理界面 + 路由模拟器
- 关联技能: `ai-provider-routing`

### 🟢 NCP-008 · 知识吸收系统 (v1.7.0)
**外部知识源 → 诺亚体系的吸收管线。** 遇到新仓库 / 配置 / 方法论时，按三步法分析、分类、落地。
- 纯技能实现，无独立代码
- 四路径吸收：标准 / 深层 / 同类对比 / 验证性
- 关联技能: `knowledge-absorption-protocol`

### 🟢 NCP-009 · 进化工作流 (v1.0.0)
**所有项目的元方法论。** 研究→立理论→研究自己→成方案→搭沙箱→验证→用到自己身上→版本迭代。
- 纯技能实现
- 进化优先级：消化 > 吸收 > 利用 > 借用
- 关联技能: `evolutionary-workflow`

### 🟢 NCP-010 · 记忆档案馆系统 (核心 v1.2.2)
**三层上下文记忆管道。** 4B 管家恒常身份层 + 大模型外壳记忆 + PG pgvector 全量检索。
- 3 个关联技能: `noah-memory-core` (v1.2.2), `retrieval-protocol` (v2.0.0), `memory-lifecycle-theory` (v0.2.0)
- PG pgvector 向量检索 + HNSW 索引
- 覆盖：对话记忆 / 知识检索 / 记忆生命周期管理
- 关联技能: `noah-memory-core`, `retrieval-protocol`, `memory-lifecycle-theory`

### 🟢 NCP-011 · 安全门闸系统 (v1.1.0)
**三层防护设计模式：** 输入过滤 / 工具调用决策 / 输出审查。钩子注册 + 规则设计 + 豁免机制。
- 3 个生产钩子注册在 Hermes 预处理/后处理管线
- 纯配置+技能实现
- 关联技能: `security-gates`

### 🟢 NCP-012 · TFC 任务系统 (v1.3.0)
**Task Flow Card 任务流转卡系统。** 需求→卡片→active→done→归档的完整生命周期。
- PG `tfc_tasks` 表持久化
- Hermes cron 驱动
- 关联技能: `tfc-workflow`

### 🟢 NCP-013 · FC 存档系统 / 全量灾备 (v2.0.0)
**RPG 风格三槽存档 + 全量灾备。** 槽位 + 读档还原。增量 / 全量 / 定时备份。
- 4 存档槽位: slot1(手动) + auto1/2/3(自动轮转)
- rsync 至广州服务器灾备
- 关联技能: `noah-full-backup`, `noah-self-preservation`

## 快速启动

```bash
# 读当前版本
psql -d noah_local -c "SELECT * FROM version_registry ORDER BY id;"

# 读项目注册
cat ~/noah-档案馆/原铸诺亚/项目注册.md

# 打开仪表盘
# 浏览器 → http://localhost:8899/原铸诺亚-仪表盘.html
```
