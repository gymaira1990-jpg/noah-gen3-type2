## 续接方法

新会话中，每个模块都有精确的续接指令（见 `模块/NCP-NNN-*.md` 的 `五、续接指令`）。

通用示例:
```
用户: 继续开发 P4 Router
诺亚: 1. 加载 skill:ai-provider-routing → 锚定资源
      2. 读取 ~/noah-档案馆/原铸诺亚/模块/NCP-007-P4-Router.md
      3. 验证环境（Python/PG/Ollama）
      4. 读 slot1 存档 → 上次进度 "Phase 1 向量语义匹配层完成"
      5. 开始 Phase 2
```
