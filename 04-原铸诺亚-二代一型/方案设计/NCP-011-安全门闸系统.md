## 3. 模块接口

| 接口 | 说明 |
|------|------|
| pre-gate hook | 请求前安全检查，分类/过滤输入 |
| decision-gate hook | 决策中安全评估，确认 AI 输出安全 |
| post-verify hook | 响应后验证，记录安全日志 |
| Skill 调用 | `security-gates` skill 直接调用 |
| Tirith 策略引擎 | 规则评估与安全策略执行 |

### 门闸流水线

```
用户输入 → [pre-gate] → AI处理 → [decision-gate] → [post-verify] → 用户输出
    ↑          |             |            |               |
    分类/校验   |         安全评估      记录验证日志
               ↓
          拒绝/放行
```
