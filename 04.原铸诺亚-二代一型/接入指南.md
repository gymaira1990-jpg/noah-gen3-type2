# 原铸诺亚·二代一型 — 接入指南

> **如何集成原铸诺亚的管理体系到你的Hermes环境**

---

## 一、前置条件

| 资源 | 要求 | 来源 |
|:-----|:------|:------|
| Hermes Agent | v0.13.x + | `pip install hermes-agent` |
| PostgreSQL | 16 + pgvector | `apt install postgresql-16 postgresql-16-pgvector` |
| Ollama | 任意版本 | `curl -fsSL https://ollama.com/install.sh | sh` |
| 在线API | DeepSeek / 豆包 / 硅基流动 | 注册后获取API Key |

## 二、模块注册方式

原铸诺亚的7个NCP模块通过三种方式接入：

### 2.1 Skill方式（占86%）

6个模块以Hermes Skill形式实现，集成即通过skill加载：

```bash
# 查看已注册技能
ls ~/.hermes/skills/core/ | grep -E 'noah|tfc|security|knowledge|evolution|backup'

# 加载技能
hermes chat --load-skill noah-memory-core
hermes chat --load-skill tfc-workflow
hermes chat --load-skill security-gates
```

### 2.2 独立工程方式（14%）

NCP-007 P4 Router 为独立Python工程：

```bash
# 部署
git clone <p4-router-repo> ~/p4-router
cd ~/p4-router && pip install -r requirements.txt && python setup.py install

# 验证
curl http://127.0.0.1:8889/admin/routes
```

### 2.3 PG数据表方式

所有持久化模块共享PG数据库 `noah_local`：

```sql
-- 检查目标表是否就绪
SELECT table_name FROM information_schema.tables 
WHERE table_schema='public' ORDER BY table_name;

-- 预期: api_call_logs, knowledge_entries, knowledge_cards, 
--        knowledge_fulltext, memory_store, route_vectors, tfc_tasks
```

## 三、快速验证清单

完成以下检查确认接入成功：

```bash
# 1. Hermes 版本
hermes --version

# 2. PG 连接
pg_isready

# 3. 知识库表
psql -U gcat -d noah_local -c "SELECT count(*) FROM knowledge_entries;"

# 4. TFC 任务
psql -U gcat -d noah_local -c "SELECT count(*) FROM tfc_tasks;"

# 5. 安全钩子
ls ~/.hermes/scripts/noah-post-verify.py

# 6. 备份脚本
ls ~/.hermes/scripts/noah-backup.sh
```

## 四、MCP工具清单

若集成本地MCP（local-knowledge），可用以下工具：

| 工具 | 用途 | 对应NCP |
|:-----|:------|:-------:|
| `search_knowledge` | 语义搜索知识库 | NCP-010 |
| `create_entry` | 创建知识条目 | NCP-010 |
| `knowledge_stats` | 知识库统计 | NCP-010 |

## 五、数据流概览

```
外部Agent ──MCP──→ local-knowledge MCP ──→ PostgreSQL
      │                                          │
      ├── NCP-011 安全门闸 ─────────────→ 钩子脚本
      │
      └── NCP-012 TFC驱动 ───cron──→ tfc_tasks表

```
