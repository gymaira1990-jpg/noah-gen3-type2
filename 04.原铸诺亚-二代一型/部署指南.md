# 原铸诺亚·二代一型 — 部署指南

> **从零搭建自己的原铸诺亚认知操作系统**

---

## 一、前置要求

| 资源 | 要求 |
|:-----|:------|
| 操作系统 | Linux (Ubuntu 22.04+ 或 WSL2) |
| 内存 | 16GB+ (推荐32GB) |
| 磁盘 | 50GB+ 可用 |
| Python | 3.11+ |
| 数据库 | PostgreSQL 14+ + pgvector |
| 嵌入模型 | Ollama + qwen3-embedding:0.6b (或同维度替代) |
| 在线API | 至少一个LLM提供商 (DeepSeek/豆包/硅基流动) |

---

## 二、快速部署

### 第一步：基础环境

```bash
# PostgreSQL + pgvector
sudo apt install postgresql-16 postgresql-16-pgvector
sudo systemctl start postgresql

# Python venv
python3 -m venv ~/noah-venv
source ~/noah-venv/bin/activate

# Hermes Agent
pip install hermes-agent
```

### 第二步：数据库初始化

```bash
# 创建数据库
sudo -u postgres createdb noah_local
sudo -u postgres psql -d noah_local -c "CREATE EXTENSION vector;"

# 建表（复制源码/schema.sql中的DDL）
psql -U postgres -d noah_local -f schema.sql
```

### 第三步：配置Hermes

```yaml
# ~/.hermes/config.yaml
model:
  default: deepseek-v4-flash
  provider: custom:deepseek

custom_providers:
  - name: custom:deepseek
    model: deepseek-v4-flash
    api_key: ${DEEPSEEK_API_KEY}
    base_url: https://api.deepseek.com/v1
```

### 第四步：部署P4 Router（NCP-007）

```bash
git clone <p4-router-repo> ~/p4-router
cd ~/p4-router
pip install -r requirements.txt
python setup.py install

# 验证
curl http://127.0.0.1:8889/admin/routes
```

### 第五步：Ollama + 嵌入模型

```bash
ollama pull qwen3-embedding:0.6b

# 验证
curl http://127.0.0.1:11434/api/tags
```

## 四、备份配置

```bash
# 增量备份（每6小时）
0 */6 * * * bash ~/.hermes/scripts/noah-backup.sh light

# 全量备份（每天02:00）
0 2 * * * bash ~/.hermes/scripts/noah-backup.sh standard

# 灾备至远端（每周日03:00）
0 3 * * 0 bash ~/.hermes/scripts/noah-backup.sh full
```

## 五、运维建议

- 每月执行一次 `VACUUM ANALYZE knowledge_entries` 保持查询性能
- 每季度检查 `knowledge_entries` 嵌入覆盖率（应维持100%）
- 关注NCP-010的 `lightweight-db` 依赖修复状态
- 保持Hermes Agent版本追踪，升级前备份完整槽位
