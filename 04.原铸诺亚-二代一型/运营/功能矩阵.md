## 二、能力拆解（按功能域）

### 路由层 (NCP-007 + NCP-009)
```
P4 Router ─┬─ 提供商路由 (DeepSeek/火山/NVIDIA/OpenRouter)
            ├─ 余额感知 + 自动降级链
            ├─ 延迟监控 + 任务类型精细路由
            ├─ pgvector 向量语义匹配 (NCP-007 Phase 1.5)
            ├─ FastAPI 管理界面 (端口独立)
            └─ 路由模拟器

进化工作流 ─┬─ 元方法论 (研究→方案→沙箱→验证→迭代)
             ├─ 进化优先级 (消化>吸收>利用>借用)
             └─ 外部方案吸收模式 (Design Proposal Ingestion)
```

### 知识层 (NCP-008)
```
知识吸收 ─┬─ 三步法 (理解→对比→分类→落地)
           ├─ 四路径 (标准/深层/同类对比/验证性)
           ├─ 元知识吸收模式
           └─ 同类源多包对比
```

### 记忆层 (NCP-010)
```
记忆档案馆 ┬─ 三层上下文管道 (4B恒常 / 外壳 / 检索)
            ├─ PG pgvector 全量知识检索 (HNSW 索引, m=16)
            ├─ 记忆生命周期管理 (活跃/衰退/休眠/唤醒/废弃)
            ├─ 双轴温度 (时间+频率)
            └─ 知识提取 + 万物之窗
```

### 安全层 (NCP-011)
```
安全门闸 ┬─ 输入过滤 (钩子钩住 LLM 输入前)
          ├─ 工具调用决策 (钩子判断是否允许执行)
          ├─ 输出审查 (钩子检查 LLM 输出后)
          ├─ 豁免机制 (bypass 指定用户/场景)
          └─ 巡检集成
```

### 运营层 (NCP-012 + NCP-013)
```
TFC任务系统 ┬─ 需求→卡片→active→done→归档
              ├─ PG tfc_tasks 持久化
              └─ Hermes cron 驱动

FC存档/灾备 ┬─ 4 槽位存档 (1 手动 + 3 自动轮转)
              ├─ 增量/全量/定时备份
              └─ rsync 广州服务器灾备
```
