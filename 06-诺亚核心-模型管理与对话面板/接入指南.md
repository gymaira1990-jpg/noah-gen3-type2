# 诺亚核心 · 接入指南

> 10 分钟从零到看到仪表盘

---

## 一、安装

### 1.1 环境要求

- Python 3.10+
- pip
- (可选) nvidia-smi —— 自动检测，用于 GPU 监控
- (可选) ollama —— 用于发现 Ollama 模型
- (可选) huggingface-cli —— 用于从 HuggingFace 下载模型

### 1.2 安装依赖

```bash
pip install pyyaml fastapi uvicorn jinja2
```

就这么 4 个包，没有别的了。

---

## 二、快速启动

### 2.1 从源码目录启动

```bash
cd 06-诺亚核心-模型管理与对话面板/源码/

# 1. 创建默认配置
python -m core init
# → ✅ 已创建: ~/.noah-core/config.yaml
# → 模型: deepseek-chat, deepseek-pro

# 2. 启动 Web 面板
python -m core serve
# → 🌐 仪表盘: http://localhost:8110/dashboard
# → 📚 模型库:  http://localhost:8110/models
```

**浏览器打开 `http://localhost:8110`，看到仪表盘就算成功。**

### 2.2 配置 CLI 快捷命令

```bash
sudo ln -sf $(pwd)/arc.sh /usr/local/bin/arc
arc list  # → 应该看到模型列表
```

## 三、配置模型

### 3.1 配置文件位置

所有配置存在 `~/.noah-core/config.yaml`，纯 YAML 格式，可直接手动编辑：

```yaml
models:
- name: deepseek-chat
  real_name: DeepSeek V4 Flash
  provider: openai
  api_base: https://api.deepseek.com/v1
  api_key_env: DEEPSEEK_API_KEY
  model_id: deepseek-chat
  type: api
  temperature: 0.7
  max_tokens: 8192
  description: 主力推理模型
```

### 3.2 设置 API Key

```bash
# 通过环境变量
export DEEPSEEK_API_KEY=sk-your-key-here

# 或写入 ~/.noah-core/.env（会自动加载）
echo "DEEPSEEK_API_KEY=sk-your-key-here" >> ~/.noah-core/.env
```

### 3.3 用 CLI 添加模型

```bash
# 交互式添加
arc add

# 批量：发现本地 Ollama 模型
arc discover

# 搜索 HuggingFace GGUF 模型
arc search qwen3
arc pull hf:Qwen/Qwen3.5-4B-Q4_K_M-GGUF
```

### 3.4 用 Web UI 添加模型

浏览器打开 `/models` 页面 → 点击「添加模型」→ 填写表单 → 保存。

## 四、模型发现

### 4.1 自动发现本地模型

```bash
arc discover
```

自动扫描：
- **Ollama** — 连接 localhost:11434
- **llama.cpp** — 扫描端口 8080, 8081, 11433-11437

### 4.2 搜索 HuggingFace

```bash
arc search qwen3
arc search deepseek
```

自动搜索 GGUF 格式模型并按下载量排序。

## 五、Web 面板功能

### 5.1 仪表盘 (/dashboard)

| 区域 | 内容 |
|:-----|:------|
| 模型状态 | 在线/离线计数 + 模型徽章 |
| 内存 | 已用/总量/空闲 + 三色进度条 |
| CPU | 核心数 + 1/5/15 分钟负载 |
| 磁盘 | 使用率进度条 |
| GPU | 型号/温度/VRAM进度条/利用率 |
| 系统信息 | 主机名/运行时间/进程数/Swap |
| 本地服务 | llama.cpp 服务状态卡片 |
| 模型详情 | 完整表格 |

### 5.2 模型库 (/models)

分类展示：可对话模型 vs 功能模型（嵌入/排序），本地 vs 云。

### 5.3 对话页

两个独立对话页：
- `/chat/deepseek` — DeepSeek 全参数对话（思考模式/流式/工具调用）
- `/chat/4b` — 本地 4B 模型对话

## 六、API 接口

所有 API 端点一览：

| 端点 | 方法 | 说明 |
|:-----|:----:|:------|
| `/api/system` | GET | 系统资源（GPU/CPU/内存/磁盘） |
| `/api/check` | GET | 所有模型状态 |
| `/api/check/{name}` | GET | 单个模型状态 |
| `/api/services` | GET | 本地服务状态 |
| `/api/models` | GET | 模型列表 |
| `/api/models` | POST | 添加模型 |
| `/api/models/{name}` | PUT | 编辑模型 |
| `/api/models/{name}` | DELETE | 删除模型 |
| `/api/models/library` | GET | 分类模型库 |
| `/api/chat/{name}` | POST | 非流式对话 |
| `/api/chat/{name}/stream` | POST | 流式对话 SSE |

完整 API 文档见 `API参考.md`。

## 八、常见问题

### Web 面板无法访问？
确保 FastAPI 和 uvicorn 已安装，检查端口 8110 是否被占用：
```bash
ss -tlnp | grep 8110
```

### GPU 不显示？
本工具通过 `nvidia-smi` 采集 GPU 数据。在 WSL 中，确保 nvidia-smi 在 PATH 中：
```bash
which nvidia-smi || echo "未找到 nvidia-smi"
```
在 Windows/WSL 中，nvidia-smi 位于 `/usr/lib/wsl/lib/nvidia-smi`，通常已自动加入 PATH。

### 模型状态显示离线？
- 检查环境变量是否正确设置
- 检查 API 地址是否可达
- 运行 `arc test <模型名>` 看具体错误信息

### 配置修改后不生效？
配置是热加载的，每次请求重新读取。如果使用 CLI 修改后仍不生效，检查 `~/.noah-core/config.yaml` 是否已更新。
