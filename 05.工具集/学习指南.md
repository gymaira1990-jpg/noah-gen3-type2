## 二、核心设计决策

### 决策1: 为什么用纯 stdlib 实现 WebSocket?

**问题：** CDP 控制需要 WebSocket 连接。现有方案用 `websockets` 或 `websocket-client` 库。

**踩坑：** WSL 环境的 `HTTP_PROXY` 环境变量指向 `127.0.0.1:7890`（Clash 代理）。
第三方库在导入时自动读取代理配置，将 CDP 的 WebSocket 连接也走代理→超时。

**方案：** 纯 stdlib 实现 WebSocket 客户端
- `socket` — 原生 TCP 连接，不受代理环境变量影响
- `http.client` — HTTP 升级握手（创建标签页）
- 自制帧解析 — 只实现必需的子集（Text + Close，不支持分片帧）

**代价：** 约 80 行代码。不处理控制帧（ping/pong），不处理分片帧。
CDP 场景不需要这些——协议本身只用 text 帧。

### 决策2: 为什么每次搜索新建标签页？

**问题：** 复用已有标签页需要管理状态、处理页面导航、等待刷新。

**方案：** 每次搜索通过 `PUT /json/new` 创建新标签页，用完即关：
```python
# 创建
PUT /json/new?url=https://www.baidu.com/s?wd=hello
→ {"id": "page_123", "webSocketDebuggerUrl": "ws://..."}

# 关闭（finally 块，异常也执行）
ws.close()
DELETE /json/close/page_123
```

**优势：**
- 不影响用户已有浏览会话（用户在干别的不受影响）
- 不会越堆越多（finally 保证关闭）
- 状态隔离（每个搜索独立页面）

### 决策3: 为什么 API > 自建搜索引擎？

**数据来源：** 在三个网络位置（VPS/家庭宽带/代理隧道）、四种传输方式（直连/SOCKS5/HTTP 代理/REALITY）、五个搜索引擎（百度/Google/Bing/DuckDuckGo/搜狗）上测试过。

**结论：** 纯 HTTP 搜索（无 JS、无 Cookies、无浏览器指纹）在所有位置都会被搜索引擎弹 CAPTCHA。

```
测试条件         → 结果
────────────────────────────────────────────
VPS 直连        → ❌ CAPTCHA (3600s 封禁)
VPS → SOCKS5    → ❌ CAPTCHA (换IP也封)
VPS → HTTP代理  → ❌ CAPTCHA
家庭宽带直连     → ❌ JS验证码页面
家庭宽带+SOCKS5 → ❌ CAPTCHA
真实浏览器 CDP   → ✅ 正常搜索
Tavily API      → ✅ 正常搜索（API 认证）
```

正确顺序：Tavily API（付费但确定）→ 真实浏览器 CDP（需桌面）→ 自建引擎（大概率被限）。

### 决策4: 注册表 vs 硬编码

**为什么用 YAML 注册表：**
- 新工具加一个 YAML 文件就够了，不修改调度代码
- 健康检查策略和降级路径在注册表中声明式定义
- 工具状态一目了然（`tool registry list`/`tool registry health`）

```yaml
# 一个工具的完整定义
name: my-tool
type: local            # local/remote/http
command: python3 tools/my_tool.py
actions:
  do: python3 tools/my_tool.py do {arg}
health:
  check: curl http://127.0.0.1:PORT/health
fallback: other-tool   # 降级路径
```

## 四、常见误解

### ❌ "CDP 只能用 Playwright/Selenium 操作"
CDP 是 HTTP + WebSocket 协议。框架只是封装了协议层。
底层就是 `curl + ws` —— 任何语言都能直接调用。

### ❌ "搜索工具链应该自己部署搜索引擎"
SearXNG 等自建引擎在 VPS 会被 CAPTCHA 封死。
API 搜索服务（Tavily/SerpAPI）是 AI Agent 的正确选择。

### ❌ "HTTP_PROXY 只影响 curl/wget"
很多 Python 库（`httpx`、`aiohttp`、`websockets`、`playwright`）
在初始化时读取 `HTTP_PROXY` 环境变量，可能导致意外的代理路由。

## 五、扩展指南

### 添加新搜索引擎

在 `edge_cdp.py` 的 `SEARCH_ENGINES` 字典添加：
```python
SEARCH_ENGINES = {
    "baidu":  "https://www.baidu.com/s?wd={query}&rn={max_results}",
    "duckduckgo": "https://duckduckgo.com/?q={query}",
}
```

### 添加新工具到注册表

创建 YAML 文件到 `tools/registry/` 目录：
```yaml
# tools/registry/my-tool.yaml
name: my-tool
type: local
command: python3 tools/my_tool.py
actions:
  run: python3 tools/my_tool.py run {arg}
health:
  check: python3 tools/my_tool.py check
```
自动发现，无需重启——`tool my-tool run <arg>` 即可调用。
