## 使用速览

```bash
# 1. 浏览器启动（带 CDP）
msedge.exe --remote-debugging-port=9222

# 2. 搜索
python3 源码/edge_cdp.py search "大语言模型"

# 3. 抓取
python3 源码/edge_cdp.py crawl "https://example.com"
```
