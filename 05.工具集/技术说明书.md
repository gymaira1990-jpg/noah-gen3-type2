## 是什么

AI Agent 在执行复杂任务时，需要一套可靠的工具链来完成搜索、抓取、检查、运维等操作。这套工具集是为 **AI Agent 设计的最小完备工具系统**，核心解决三个问题：

1. **真实浏览器搜索** — 纯 Python stdlib 实现 Chrome/Edge CDP 协议控制，绕过搜索引擎 CAPTCHA
2. **统一工具管理** — 注册表驱动的 CLI 接口，所有工具通过 YAML 定义，按需加载、健康检查、优雅降级
3. **核心搜索管线** — 搜索 → 重排序 → 抓取 → 摘要的三层管线设计

## 核心组件

### 1. Edge CDP 浏览器控制 (`edge_cdp.py`)

**纯 Python stdlib 实现** — 不依赖 Playwright/Selenium/任何第三方库。

| 特性 | 说明 |
|:-----|:------|
| 协议 | Chrome DevTools Protocol (CDP) over bare WebSocket |
| 依赖 | **零外部依赖** — 只用 `os/socket/struct/base64/http.client/json` |
| 架构 | WSL → 原生 TCP socket → HTTP 创建标签页 → 自制 WebSocket 帧解析 |
| 隔离 | 每次搜索创建新标签页，用完即关，不污染用户浏览会话 |

**为什么裸写 WebSocket：**
- AI Agent 环境（特别是 WSL/Linux）往往有 HTTP_PROXY 环境变量
- Playwright/websockets 库在导入时被代理污染，CDP 连接超时
- 纯 stdlib 实现完全不受代理环境变量影响

**核心类：**
```python
class RawWS:
    """无依赖的 WebSocket 客户端"""
    def __init__(self, path):    # TCP 连接 + HTTP 升级握手
    def send(self, data):        # WebSocket 帧编码（带 MASK）
    def recv(self, timeout=10):  # WebSocket 帧解码（服务器帧无 MASK）
    def close(self):             # 关闭连接
```

### 2. 统一工具管理 CLI (`tool`)

**注册表驱动的工具发现系统。**

| 概念 | 说明 |
|:-----|:------|
| 注册表 | 每个工具一个 YAML 文件，定义名称/命令/端口/健康检查/优雅降级 |
| 调度器 | 自动发现注册表，按命令路由到对应工具 |
| 健康检查 | 端口探测 + 命令执行 + HTTP 端点轮询 |
| 降级策略 | 主工具不可用时自动切备用（如 Tavily API → Edge CDP → SearXNG） |

```yaml
# 示例: edge-search.yaml (工具注册表条目)
name: edge-search
type: local
command: python3 scripts/edge_cdp.py
actions:
  search: python3 scripts/edge_cdp.py search {query} {engine}
  crawl:  python3 scripts/edge_cdp.py crawl {url}
  check:  python3 scripts/edge_cdp.py check
health:
  check: python3 scripts/edge_cdp.py check
```

### 3. 搜索管线

```
用户搜索
  → P0: Tavily Search API     (最快，2-5s，无CAPTCHA)
  → P1: Edge CDP 真实浏览器   (备用，4-15s，需要Win11+Edge运行)
  → P2: 自建搜索引擎          (冷备，大概率被限速)
  → 可选: 语义重排序          (Reranker 提升结果质量)
  → 可选: 页面抓取+提取       (Crawl/Extract)
```

## 设计哲学

1. **API优先，浏览器次之，自建最后** — 对于 AI Agent 场景，API 服务的确定性远高于自建方案
2. **代码锁死，不依赖承诺** — 每次修改都要是代码/配置锁死的永久修复，不是"下次注意"
3. **优雅降级** — 任何工具不可用时，自动切到下一个可用通道，不阻塞业务流程
4. **零依赖优先** — 能用 stdlib 就不用第三方库，减少兼容性问题
5. **先验证，再说"完成了"** — 每条声称都必须通过实际命令验证
