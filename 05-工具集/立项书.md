# 立项书 · AI 智能工具集

> **05 · 工具集**
> 版本: v1.0.0 · 状态: 🟢 生产就绪 · 创建: 2026-05-25

---

## 背景

AI Agent 在执行复杂任务时，需要与外部世界交互的工具链。在开发诺亚认知架构的过程中，我们积累了一套工具系统——从最基础的浏览器 CDP 控制，到统一工具管理 CLI，到多层搜索管线。

这些工具独立于任何 LLM 框架，通用性强，决定以独立项目形式开源分享。

## 解决的问题

1. **AI Agent 搜索困难** — 搜索引擎对非浏览器 HTTP 请求弹 CAPTCHA
2. **工具管理碎片化** — 每个工具一个入口，无统一调度/健康检查/降级
3. **Playwright/Selenium 太重** — 为简单浏览器控制引入大量依赖不合适

## 核心能力

| 能力 | 说明 |
|:-----|:------|
| 真实浏览器搜索 | 纯 stdlib CDP 控制，绕过 CAPTCHA |
| 统一工具管理 | 注册表驱动，YAML 定义，自动发现 |
| 搜索管线 | 搜索 → 重排 → 抓取 → 摘要 |
| 健康监控 | 组件存活检测 + 浏览器看门狗 |
| 优雅降级 | API 不可用时自动切下一通道 |

## 不做什么

- ❌ 不做 LLM 框架（只做工具层，可集成到任何 Agent 框架）
- ❌ 不做自建搜索引擎（SearXNG 等，已证明 VPS 场景不可用）
- ❌ 不做浏览器自动化框架（只做搜索和抓取，不做表单填写/点击）
- ❌ 不做 Docker 部署（只提供 apt/pip 裸装模式）

## 技术栈

- Python 3 (stdlib only — `socket/http.client/json`)
- Chrome DevTools Protocol over WebSocket
- YAML (注册表格式)
- Bash (健康检查脚本)

## 设计原则

1. **零依赖优先** — 能用 stdlib 不用第三方库
2. **API > 自建** — API 服务的确定性远高于自建方案
3. **代码锁死** — 修复必须用代码/配置永久锁死，不依赖行为承诺
4. **优雅降级** — 任何组件故障不阻塞业务流程
