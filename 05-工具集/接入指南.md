# 05 · 工具集 · 接入指南

> 🔌 10 分钟集成 · 最小示例 · 验证清单

---

## 前置条件

| 依赖 | 版本 | 备注 |
|:-----|:----:|:-----|
| Python 3 | ≥ 3.8 | 纯 stdlib，无需 pip install |
| Edge/Chrome | ≥ 120 | 需要 CDP 支持（启动时加 `--remote-debugging-port=9222`） |

---

## 第一步：启动浏览器 CDP

### Windows (Edge)
```cmd
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" ^
  --remote-debugging-port=9222 ^
  --user-data-dir="C:\EdgeProfile"
```

### macOS (Chrome)
```bash
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9222 \
  --user-data-dir=/tmp/chrome-profile
```

### Linux (Chromium)
```bash
chromium-browser --remote-debugging-port=9222 \
  --user-data-dir=/tmp/chromium-profile
```

> ⚠️ Windows 11 Edge 148+ 只监听 IPv6 `[::1]:9222`。
> 如果从 WSL/Linux 容器访问，需要端口转发：
> ```cmd
> netsh interface portproxy add v4tov6 listenport=9222 listenaddress=0.0.0.0 connectport=9222 connectaddress=::1
> ```

### 验证
```bash
curl http://127.0.0.1:9222/json/version
# → {"Browser": "Edg/148.0.0", ...}  (有输出即成功)
```

## 第二步：运行搜索

```bash
# 检查连接
python3 edge_cdp.py check

# 搜索（默认百度）
python3 edge_cdp.py search "人工智能"

# 指定引擎
python3 edge_cdp.py search "rust async" google

# 抓取页面
python3 edge_cdp.py crawl "https://example.com"
```

## 配置项

| 环境变量 | 默认值 | 说明 |
|:---------|:------:|:-----|
| `CDP_HOST` | `127.0.0.1` | 浏览器 CDP 监听地址 |
| `CDP_PORT` | `9222` | 浏览器 CDP 监听端口 |

---

## 降级策略

| 失败场景 | 降级行为 |
|:---------|:---------|
| 浏览器未启动 | 返回 `{"connected": false}`，建议启动浏览器 |
| CDP 端口被占 | 修改端口重启浏览器，更新环境变量 |
| 标签页创建失败 | 重试 1 次，仍失败则返回错误 |
| 搜索结果为空 | 返回空 `links` 数组，不抛异常 |
| 页面加载超时 | 返回已提取的内容（部分结果） |

---

## 最小集成示例

```python
from edge_cdp import edge_search, edge_crawl

# 搜索
result = edge_search("Python asyncio", engine="google")
for link in result["links"]:
    print(f"  {link['title']}: {link['url']}")

# 抓取
page = edge_crawl(result["links"][0]["url"])
print(f"抓取: {page['title']} ({page['content_len']} chars)")
```
