# Mnemosyne 记忆宫殿 · 部署指南

> **从零搭建自己的外挂记忆系统**

---

## 一、前置要求

| 资源 | 要求 |
|:-----|:------|
| 服务器 | Linux (Ubuntu 22.04+), 2 核+, 至少 1GB 内存 |
| 数据库 | PostgreSQL 14+ + pgvector 扩展 |
| 嵌入 | Ollama + embedding 模型 (如 qwen3-embedding:0.6b) |
| Python | 3.11+ |

---

## 二、快速部署

### 第一步：数据库

```sql
-- 创建数据库和用户
CREATE DATABASE mnemosyne;
CREATE USER mnemosyne WITH PASSWORD 'your_password';
\c mnemosyne

-- 启用扩展
CREATE EXTENSION vector;
CREATE EXTENSION pg_trgm;

-- 建核心表
CREATE TABLE memories (
    id BIGSERIAL PRIMARY KEY,
    user_id TEXT NOT NULL,
    project_id TEXT,
    content TEXT NOT NULL,
    category TEXT DEFAULT 'fact',
    embedding VECTOR(1024),
    importance FLOAT DEFAULT 0.5,
    heat_score FLOAT DEFAULT 0.5,
    tier TEXT DEFAULT 'L2',
    access_count INT DEFAULT 0,
    last_accessed TIMESTAMPTZ DEFAULT NOW(),
    is_deleted BOOLEAN DEFAULT FALSE,
    metadata JSONB DEFAULT '{}',
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- HNSW 向量索引
CREATE INDEX idx_memories_embedding ON memories 
    USING hnsw (embedding vector_cosine_ops) WITH (m=16, ef_construction=200);
CREATE INDEX idx_memories_lookup ON memories (user_id, tier, heat_score);
CREATE INDEX idx_memories_category ON memories (user_id, category);
```

### 第二步：FastAPI 引擎

```bash
# 创建部署目录
sudo mkdir -p /opt/mnemosyne
sudo chown $USER:$USER /opt/mnemosyne
cd /opt/mnemosyne

# Python 环境
python3 -m venv venv
source venv/bin/activate
pip install fastapi uvicorn httpx asyncpg psycopg2-binary

# 创建主文件 (见下方/源码)
touch main.py

# 测试运行
uvicorn main:app --host 127.0.0.1 --port 8010
```

### 第三步：systemd 服务

```ini
# /etc/systemd/system/mnemosyne.service
[Unit]
Description=Mnemosyne Memory Palace
After=network.target postgresql.service

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/opt/mnemosyne
Environment=PATH=/opt/mnemosyne/venv/bin
Environment=PG_DSN=postgresql://mnemosyne:password@localhost/mnemosyne
Environment=OLLAMA_URL=http://127.0.0.1:11434
ExecStart=/opt/mnemosyne/venv/bin/uvicorn main:app --host 127.0.0.1 --port 8010
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable mnemosyne
sudo systemctl start mnemosyne
sudo systemctl status mnemosyne
```

### 第四步：Reflector Cron

```bash
# light: 每小时
echo '0 * * * * ubuntu cd /opt/mnemosyne && venv/bin/python -c "from reflect import light_reflect; light_reflect()"' | sudo tee /etc/cron.d/mnemosyne-light

# deep: 每天凌晨 4 点
echo '0 4 * * * ubuntu cd /opt/mnemosyne && venv/bin/python -c "from reflect import deep_reflect; deep_reflect()"' | sudo tee -a /etc/cron.d/mnemosyne-deep
```

### 第五步：验证

```bash
# 健康检查
curl http://localhost:8010/health
# → {"status": "ok", "db": "connected", "embedding": "ready"}

# 存一条
curl -X POST http://localhost:8010/memories \
  -H "Content-Type: application/json" \
  -d '{"user_id":"test","content":"Hello Mnemosyne","category":"fact"}'

# 搜
curl -X POST http://localhost:8010/memories/search \
  -H "Content-Type: application/json" \
  -d '{"user_id":"test","query":"Hello","top_k":5}'
```

## 三、MCP 集成

如果使用 Hermes Agent，在 `~/.hermes/plugins/gz-crawl/` 的 MCP Server 配置中注册 Mnemosyne 工具：

```python
@server.tool("memory_store")
async def memory_store(
    user_id: str,
    content: str,
    category: str = "fact",
) -> str:
    """存储一条记忆"""
    async with httpx.AsyncClient() as client:
        r = await client.post(
            f"http://127.0.0.1:8010/memories",
            json={"user_id": user_id, "content": content, "category": category},
            timeout=30,
        )
        return r.text
```

如果使用其他 MCP 客户端，添加：

```json
{
  "mcpServers": {
    "mnemosyne": {
      "url": "http://<your-server>:8010/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}
```

## 四、可选增强

| 增强 | 说明 | 难度 |
|:-----|:-----|:----:|
| Reranker 重排序 | 在语义搜索结果上用 cross-encoder 重排，提升精度 | 低 |

## 五、生产注意事项

1. **端口绑定** — FastAPI 绑 `127.0.0.1`，不对外暴露。通过 SSH 隧道或 Nginx 代理访问
2. **数据库密码** — 存 `.env` 文件，不硬编码在 systemd service 里
3. **Ollama 嵌入模型** — `qwen3-embedding:0.6b` 是轻量级，精度够用但不如 1.5b。如果服务器内存够（>4GB），用更大的嵌入模型
4. **HNSW 参数** — `m=16, ef_construction=200` 适合百万级。如果数据量千万级，调大到 `m=32, ef_construction=400`
5. **日志轮转** — FastAPI 日志默认不轮转。加 `logrotate` 配置防磁盘满了
6. **备份** — pg_dump mnemosyne 数据库定期备份
