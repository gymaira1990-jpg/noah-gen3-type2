# 立项书 · Mnemosyne 记忆宫殿

> 诺亚三代二型 · 子项目 02
> 状态: ✅ 生产就绪 · 2026-05-22

---

## 项目定位

**将远程服务器打造成独立的外挂记忆宫殿——AI Agent 通过 MCP 协议调用的永久记忆与知识中枢。**

## 做什么

| # | 能力 | 说明 |
|:-:|:-----|:------|
| 1 | 永久记忆存储 | 文本记忆 + 多模态描述，自动分类/嵌入 |
| 2 | 四维检索 | 语义向量 + 关键词 + 时序 + 图遍历 |
| 3 | 热度遗忘 | 四层自动衰减，L1热→L4归档 |
| 4 | 自我进化 | Writer-Reader 反馈闭环，去重/合并/实体提取 |
| 5 | 知识图谱 | Apache AGE 图数据库，实体关系多跳查询 |
| 6 | MCP 标准 | 33 个工具，任意 MCP 客户端零适配 |

## 不做什么

1. ❌ 不做对话生成（Agent 自己做推理）
2. ❌ 不做视觉理解（Agent 的多模态模型做完后传文本）
3. ❌ 不做路由/中间件（只做记忆存储与检索）
4. ❌ 不迁移已有数据（从零开始，独立数据库）

## 交付规模

| 维度 | 数据 |
|:-----|:-----|

| FastAPI 端点 | ~32 个 |
| 代码量 | ~3,500 行 |
| 内存占用 | ~280 MB |
