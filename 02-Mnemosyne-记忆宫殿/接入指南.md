# Mnemosyne 记忆宫殿 · 接入指南

> **让你的 AI Agent 拥有外挂记忆**

---

## 一、集成方式

Mnemosyne 全部通过 **MCP 协议** 暴露接口。你只需要在 Agent 的 MCP 配置中添加一个服务端指向即可。

### MCP 配置

```json
{
  "mcpServers": {
    "mnemosyne": {
      "url": "http://<server>:8001/mcp",
      "headers": {
        "Authorization": "Bearer <your-token>"
      }
    }
  }
}
```

> 或者修改已有 MCP Server 的配置文件，添加 Mnemosyne 工具注册。

## 二、数据流

### 写入一条记忆

```
Agent 调用: memory_store(category="fact", content="<记忆内容>")
  ↓
MCP 工具桥接 → FastAPI :8010 → 生成 embedding (Ollama :11434)
                                  ↓
                             写入 PG mnemosyne.memories
                                  ↓
                             更新 memory_traces
                                  ↓
                             返回 {id: 123, status: "stored"}
```

### 检索记忆

```
Agent 调用: memory_recall(query="<搜索词>", top_k=5)
  ↓
MCP 工具桥接 → FastAPI :8010 → 生成查询 embedding (Ollama :11434)
                                  ↓
                             HNSW 向量搜索 (pgvector)
                                  ↓
                             关键词补充 (pg_trgm)
                                  ↓
                             融合排序返回
                                  ↓
                             更新 access_count + heat_score
                                  ↓
                             返回 [{id, content, heat_score, ...}]
```

### 图片/多模态记忆

```
Agent 收到图片 → 调用多模态模型理解 → 获得文本描述
  ↓
Agent 调用: memory_store_multimodal(
    content="<视觉理解文本描述>",
    media_type="image",
    media_url="<原始图片链接>"
)
  ↓
Mnemosyne 存储到 media_memories 表
```

## 四、最小接入示例

```python
"""从 Python 调用 Mnemosyne 记忆宫殿"""

import httpx

MNEMOSYNE_URL = "http://<server>:8010"

def store_memory(content: str, category: str = "fact", 
                 importance: float = 0.5) -> dict:
    """存储一条记忆"""
    resp = httpx.post(f"{MNEMOSYNE_URL}/memories", json={
        "user_id": "agent-001",
        "content": content,
        "category": category,
        "importance": importance,
    })
    return resp.json()

def recall(query: str, top_k: int = 5) -> list:
    """搜索记忆"""
    resp = httpx.post(f"{MNEMOSYNE_URL}/memories/search", json={
        "user_id": "agent-001",
        "query": query,
        "top_k": top_k,
    })
    return resp.json()["results"]

def get_heat_top(limit: int = 10) -> list:
    """获取最热记忆"""
    resp = httpx.get(f"{MNEMOSYNE_URL}/memories/heat-top",
                     params={"user_id": "agent-001", "limit": limit})
    return resp.json()

# 使用
store_memory("2026-05-22: 完成了 Mnemosyne 项目，33个MCP工具交付")
results = recall("Mnemosyne 工具")
print(results)
```

## 五、配置项

| 配置 | 默认 | 说明 |
|:-----|:-----|:-----|
| `FASTAPI_PORT` | 8010 | FastAPI 引擎端口 |
| `MCP_PORT` | 8001 | MCP 协议端口 |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | 嵌入向量化服务 |
| `RERANKER_URL` | `http://127.0.0.1:11436` | 重排序服务 |
| `LLMLINGUA_URL` | `http://127.0.0.1:11437` | 文本压缩服务 |
| `PG_DSN` | `postgresql://mnemosyne@localhost/mnemosyne` | 数据库连接 |
| `HEAT_DECAY` | 0.95 | 每日热度衰减率 |
| `REFLECT_LIGHT_CRON` | `0 * * * *` | 每小时 light 反思 |
| `REFLECT_DEEP_CRON` | `0 4 * * *` | 每天凌晨 deep 反思 |

## 六、验证命令

```bash
# 健康检查
curl http://localhost:8010/health

# 存一条记忆
curl -X POST http://localhost:8010/memories \
  -H "Content-Type: application/json" \
  -d '{"user_id":"test","content":"测试记忆","category":"fact"}'

# 搜索
curl -X POST http://localhost:8010/memories/search \
  -H "Content-Type: application/json" \
  -d '{"user_id":"test","query":"测试","top_k":3}'

# 最热
curl "http://localhost:8010/memories/heat-top?user_id=test&limit=5"
```
