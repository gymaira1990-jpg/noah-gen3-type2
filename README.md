## 🎯 使命

### 核心命题

> **如何让一个大语言模型在无限长的对话中，永远：**

| # | 能力 | 解决的问题 | 实现方式 |
|:-:|:-----|:-----------|:---------|
| 1 | 🧠 记得刚做过什么 | 压缩后失忆 | 执行日志 PROTECTED 固化 |
| 2 | 📝 记得用户纠正过什么 | 重复犯错 | 纠正永久保护，同hash不重复 |
| 3 | 📂 记得正在做什么 | 活跃项目丢失 | 项目进度追踪+渐进摘要 |
| 4 | 📌 记得做过的决策 | 方向反复 | 决策记录保护+冷储可回溯 |
| 5 | 🗑️ 不记得寒喧废话 | Token浪费 | 纯正则噪音过滤，零LLM |
| 6 | 🔁 不重复犯错 | 效率低下 | 重复检测+历史方案比对 |
| 7 | 💰 花最少的钱 | 压缩成本高 | 100%免费模型完成所有压缩 |

### 设计哲学

1. **零幻觉优先** — 机械规则兜底，不依赖 LLM 做关键判断
2. **渐进非暴力** — 每次只压缩满的抽屉，不一次性全量压缩
3. **保护先于压缩** — 关键信息永远不能被压缩丢失
4. **免费优先** — 能用正则不做 LLM，能用免费模型不用付费
5. **一劳永逸** — 修复必须是代码锁死的永久方案
6. **独立于框架** — 不绑定特定 Agent 框架，提供适配器层

## 🏛️ 原铸诺亚的血统

本项目继承自 **原铸诺亚原型机 0101 型**（noah-prime），一个在大模型 Agent 实战中成长起来的上下文管理系统。

```
原铸诺亚 (noah-prime)         ← 实战验证: 数万轮对话, 30模块, 15,123行
    │
    └── 经验萃取: 抽屉级联 + 记忆管家 + 上下文组装
             │
             ▼
        诺亚三代·二型          ← 解耦为通用方案, 独立于任何框架
         (noah-gen3-type2)       公开发布, MIT 许可证
```

核心创新点（经实战验证）：
- **抽屉级联** — 替代「一次性全量压缩」为 N=3 小抽屉递进压缩
- **温度=命中次数** — 替代时间衰减，确保重要内容不因时间流逝被遗忘
- **保护>去重>更新** — 三问题正交解耦，key 身份制保证版本认可最新的
- **免费模型路由** — 三链降级：GLM-4-Flash → Qwen3-8B → DeepSeek Flash
